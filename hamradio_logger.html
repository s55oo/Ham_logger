How this works

New contacts are entered in the row at the top. Once logged, they're listed below it with the most recent QSO first. Your log is kept in this browser (it will still be here next time you open this file).

Use Connect ADIF File once to pick or create an .adi file on your computer — every QSO you log afterwards is appended to it automatically. Export ADIF re-downloads the full log as a fresh .adi file any time, and works even if auto-save isn't connected (e.g. in Firefox).

Send Log hands the .adi file to your phone or computer's share sheet (Mail, Gmail, Outlook, etc. — whatever you pick) so it arrives already attached. If your browser can't do that, it downloads the file and opens a blank email instead, so you can attach it yourself.

Deleting a row removes it from this page and future exports, but not from a file that was already auto-saved.

Press Alt+W to wipe the entry row you're currently filling in; press it again while the row is empty to bring back what you just wiped.

Mode, Frequency and the RST fields carry over from one logged QSO to the next as defaults, since they rarely change between consecutive contacts.
